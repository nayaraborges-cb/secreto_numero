# 🎮 Jogo de Adivinhação

Uma página web simples onde o usuário precisa adivinhar qual é o número secreto.  
O jogo gera um número aleatório e dá dicas se o palpite do jogador é **maior** ou **menor** do que o número correto.

---

## 🚀 Funcionalidades
- Gera um número aleatório automaticamente.
- O usuário pode inserir palpites.
- Informa se o número correto é maior ou menor.
- Exibe mensagem de vitória quando o jogador acerta.

---
